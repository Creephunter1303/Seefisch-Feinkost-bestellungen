# App veröffentlichen (GitHub Pages, kostenlos)

Die App besteht nur aus den Dateien im Ordner `app/`. Sie wird automatisch auf **GitHub Pages**
veröffentlicht, sobald eine neue Version im Repo `Creephunter1303/Seefisch-Feinkost-bestellungen`
landet. Im Code stehen weder Kundendaten noch Zugangsschlüssel – deshalb darf das Repo öffentlich sein.

**Adresse der App:** https://creephunter1303.github.io/Seefisch-Feinkost-bestellungen/

## Einmalig einschalten

1. Auf github.com das Repo **Seefisch-Feinkost-bestellungen** öffnen.
2. Oben **Settings** → links **Pages**.
3. Unter „Build and deployment" → **Source** → **„GitHub Actions"** auswählen. (Mehr ist nicht nötig.)
4. Oben auf den Reiter **Actions** → „App veröffentlichen" → falls dort ein roter Lauf steht:
   anklicken → **„Re-run all jobs"**. Nach ca. 1 Minute ist die App unter der Adresse oben erreichbar.

## Updates

Neue Versionen lade ich ins Repo hoch; GitHub veröffentlicht sie in 1–2 Minuten automatisch.
Die Tablets holen sich die neue Version beim nächsten Öffnen der App von selbst
(Prüfen: ⚙ Einstellungen → „Über diese App" → Versionsnummer).
